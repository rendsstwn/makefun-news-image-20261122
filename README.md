Sum up the world's news of Sunday 22 November 2026 in one image. The entry program writes a 1024x1024 PNG summarising the day: COP31 collapses in Antalya, Iran strikes in Bahrain and tankers near the Strait of Hormuz, Trump, Xi and Putin meet in Shenzhen, cartel boss 'El Chapo Isidro' is captured in Mexico, a missile hits Kryvyi Rih in Ukraine, and markets fall into correction (S&P 500 -3.7%, Nasdaq -5.3%). Sources: Reuters, AP, AFP, Al Jazeera, 22 Nov 2026.

## Run it

```sh
python3 main.py
```

This writes `/output/entry.png` (1024x1024 PNG, about 134 KB). The program copies `entry.png` from this repository, with no network, no randomness and no timestamps, so two runs write the same bytes.
